# 実画面の手動確認

開発サーバーと `.env.local` の公開キーがあれば、ブラウザで家計の操作を確認できる。認証ユーザーはメール確認済みの確認用アカウントを用意してある。パスワードはリポジトリに含めず `.secrets/manual-check.env` に置く。

## 起動

1. `npm run dev`（既定で `.env.local` を読む）
2. ブラウザで [http://localhost:3001](http://localhost:3001) を開く（3000 が使用中なら 3001）
3. 未ログインなら `/login` へ送られる

## ログイン

`.secrets/manual-check.env` の `MANUAL_CHECK_EMAIL` と `MANUAL_CHECK_PASSWORD` を使う。

確認できること:

- 家計画面（要約 → 記録を追加 → 明細）
- 支出または収入の追加と円表示
- 月の切替（`?month=`）
- 編集、削除（確認ダイアログのあと）
- ログアウト後に `/` へ戻るとログインを求められる

登録画面から新規に作る場合、プロジェクトで確認メールが必須だとセッションが立たず家計へ進めない。そのときはダッシュボードで Confirm email を切るか、確認用アカウントでログインする。
