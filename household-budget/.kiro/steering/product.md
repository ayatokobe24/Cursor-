# Product Overview

household-budget は、個人の収支を記録・把握するための家計簿アプリケーションである。対象は世帯共有ではなく、自分の家計を一人で管理したい人である。

仕様は `.kiro/specs/` で段階的に定義する。実装は仕様承認後に進める。現状の画面は Next.js の初期テンプレートであり、家計簿機能は未実装である。

## Core Capabilities

プロダクトとして目指す核は次のとおり。詳細な画面やルールは仕様で確定する。

- 収入と支出の記録
- 記録の一覧と振り返り
- 期間ごとの収支の把握

## Target Use Cases

対象ユーザーは、個人で家計管理をしたい人である。

- 日々の支出をすばやく残し、後から確認する
- 収入と支出を突き合わせ、月次のバランスを見る

テンプレート画面の「Getting Started」はプロダクト価値ではない。

## Value Proposition

記録の負担を下げ、自分の家計の見通しをよくすることに価値を置く。機能追加は網羅ではなく、個人の収支管理に直結するかを基準にする。複数人での共有家計は対象外とする。
